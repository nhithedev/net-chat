Net-Chat – Báo cáo tiến độ

Bài tập lớn Lập trình mạng · Ứng dụng chat dùng socket TCP thuần, giao thức tự thiết kế (protocol v2)

1. Hướng đi

Nhóm chuyển từ kiến trúc Gateway Node.js + WebSocket sang Electron + lõi C + TCP thô, không dùng HTTP/WebSocket. Lý do: ở kiến trúc cũ, đăng nhập, gửi tin… đều là việc của tầng ứng dụng (web), còn TCP chỉ là đường truyền. Ở kiến trúc mới, chính chương trình của nhóm tự đọc/ghi socket, tự tách khung (framing), tự đánh số gói, tự xử lý lỗi.

  • Xử lý luồng TCP (stream): tự ghép khung từ dòng byte, chịu được gói bị cắt/dính.
  • Socket I/O: server epoll đơn luồng; client dùng poll.
  • Đặc tả đầy đủ trong protocol-v2.md.

3. Giao thức v2 (đã cài đặt)

Khung TCP – 12 byte header

length
4B
seq
4B
ack
4B
payload (JSON, 1…65536 byte)
  • Big-endian; seq bắt đầu từ 1, tăng dần; ack = seq cuối đã nhận.
  • Server phát hiện gói trùng (bỏ) và khuyết seq (ghi log).
  • HELLO bắt tay ở dạng rõ → từ đó payload mã hóa Caesar (+3 mỗi byte); header giữ nguyên để dễ ghép khung.
  • Thông điệp JSON: request {type,id,data} → response TYPE_RES (ok/error) → sự kiện đẩy EVT_*.
  • Mã lỗi: 1 sai yêu cầu · 2 chưa đăng nhập · 4 chưa là bạn · 6 đã tồn tại · 1001/1002/1003 lỗi tài khoản.
  • Chống spam: giới hạn 20 message/giây mỗi kết nối.

7. Cách demo

Server + kịch bản 2 người dùng (hiện cả seq/ack và payload)

cd server
export NETCHAT_DB="host=127.0.0.1 port=5432 dbname=chat user=chat password=chat"
make && ./build/netchat-server              # cổng 9000
python3 -I tests/demo_chat.py       # 8 bước: đăng ký → kết bạn → chat → rớt mạng → offline

Ứng dụng đầy đủ (Electron)

cd client/native && make            # build lõi C
cd .. && npm run build && npx electron .

Có thể mở Wireshark trên lo, cổng 9000: thấy header 12 byte rõ ràng, payload đã bị dịch +3.

9. Đối chiếu barem

  • Xử lý stream (1đ): có – khung 12B, bộ ghép khung, test cắt/dính gói.
  • Socket I/O (2đ): có – epoll phía server, poll phía lõi client, toàn bộ bằng C thuần.
  • Chức năng + giao diện (3đ): đang làm – đăng ký/đăng nhập có giao diện; bạn bè/chat đã chạy ở server, chưa lên giao diện; file chưa có.
